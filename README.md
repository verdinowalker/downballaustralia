# Downball Australia — Downball World Cup

This repository contains the Downball Australia web application: a tournament and league management system ("Downball World Cup") built with Next.js, TypeScript, Tailwind CSS and Supabase.

This initial branch includes the project scaffold, database schema and README with setup instructions to get started.

Goals:
- Admin dashboard at /admin to manage competitions, teams, players, fixtures, news and more.
- Public site with home, news, fixtures, results, teams, players and World Cup pages.
- Supabase used for authentication, database and file storage.

See README.md for setup and deployment instructions.
